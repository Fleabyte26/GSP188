# GSP188 – Deploying the Quiz App to Google Kubernetes Engine

## Setup (edit to match your lab panel)

```
echo us-east1 > ~/region
echo us-east1 > ~/appregion
echo us-east1-b > ~/zone
gcloud config get project > ~/project
cat ~/region ~/appregion ~/zone ~/project
```

## Block 1 – Configure the Quiz application

```
gcloud storage cp -r gs://`cat ~/project`-assets/kubernetesengine ~/
cd ~/kubernetesengine/start
sed -i -e "s/us-central1/`cat ~/region`/g" -e "s/us-central/`cat ~/appregion`/g" -e "s/python3/python3.12/g" prepare_environment.sh
. prepare_environment.sh
printenv GCLOUD_BUCKET > ~/bucket
cat ~/bucket
```

Check my progress: Configure the Quiz application

## Block 2 – Create and connect to the cluster

```
gcloud container clusters create quiz-cluster --zone `cat ~/zone` --num-nodes 3 --scopes cloud-platform
gcloud container clusters get-credentials quiz-cluster --zone `cat ~/zone`
kubectl get pods
```

Check my progress: Create Kubernetes engine cluster

## Block 3 – Create the Docker repository

```
gcloud artifacts repositories create container-dev-repo --repository-format=docker --location=`cat ~/region` --description="Docker repository for Container Dev Workshop"
```

Check my progress: Create a Docker Repository

## Block 4 – Write Dockerfiles and build images

```
cd ~/kubernetesengine/start
cat > frontend/Dockerfile <<'EOF'
FROM gcr.io/google_appengine/python
RUN virtualenv -p python3.7 /env
ENV VIRTUAL_ENV /env
ENV PATH /env/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
ADD requirements.txt /app/requirements.txt
RUN pip install -r /app/requirements.txt
ADD . /app
CMD gunicorn -b 0.0.0.0:8080 quiz:app
EOF
cat > backend/Dockerfile <<'EOF'
FROM gcr.io/google_appengine/python
RUN virtualenv -p python3.7 /env
ENV VIRTUAL_ENV /env
ENV PATH /env/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
ADD requirements.txt /app/requirements.txt
RUN pip install -r /app/requirements.txt
ADD . /app
CMD python -m quiz.console.worker
EOF
echo `cat ~/region`-docker.pkg.dev/`cat ~/project`/container-dev-repo/quiz-frontend:v1 > ~/feimage
echo `cat ~/region`-docker.pkg.dev/`cat ~/project`/container-dev-repo/quiz-backend:v1 > ~/beimage
gcloud builds submit -t `cat ~/feimage` ./frontend/
gcloud builds submit -t `cat ~/beimage` ./backend/
```

Check my progress: Build Docker Images using Cloud Build

## Block 5 – Fill in the YAML and deploy

```
cd ~/kubernetesengine/start
sed -i -e "s#\[GCLOUD_PROJECT\]#`cat ~/project`#g" -e "s#\[GCLOUD_BUCKET\]#`cat ~/bucket`#g" -e "s#\[FRONTEND_IMAGE_IDENTIFIER\]#`cat ~/feimage`#g" frontend-deployment.yaml
sed -i -e "s#\[GCLOUD_PROJECT\]#`cat ~/project`#g" -e "s#\[GCLOUD_BUCKET\]#`cat ~/bucket`#g" -e "s#\[BACKEND_IMAGE_IDENTIFIER\]#`cat ~/beimage`#g" backend-deployment.yaml
kubectl create -f ./frontend-deployment.yaml
kubectl create -f ./backend-deployment.yaml
kubectl create -f ./frontend-service.yaml
```

Check my progress: Create Kubernetes Deployment and service resources
